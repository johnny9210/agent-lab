# 워크숍 비용 계산

기획안을 쓰는 쪽과 검토하는 쪽이 같은 방법으로 계산하기 위한 순서다. 기억이나 기획안에 적힌 숫자를 쓰지 않고, 매번 견적 파일을 열어 다시 계산한다.

## 순서

1. `data/people.csv`에서 참가 인원을 직접 센다. 머리글 줄은 빼고 센다.
2. 고른 후보마다 견적 파일에서 금액과 부가세 열을 그대로 옮긴다.
   - 숙소: `data/venues.csv`의 1인숙박비, 세미나실대여료
   - 식당: `data/meals.csv`의 1인가격. 1일차 저녁과 2일차 점심을 따로 적는다
   - 교통: `data/transport.csv`의 대당왕복요금과 대수
   - 프로그램: `data/programs.csv`의 1인비용
3. 부가세 열이 '별도'이면 금액에 10%를 더한다. '포함'이면 그대로 쓴다. 부가세 열이 없는 파일은 금액을 그대로 쓴다. 숙소는 숙박비와 세미나실 대여료에 모두 적용한다.
4. 1인 단위 금액(숙박, 식사, 프로그램)은 참가 인원을 곱한다. 단체 금액(세미나실, 교통)은 곱하지 않고 그대로 더한다.
5. 합계를 내고, 합계를 참가 인원으로 나눠 1인당 비용을 낸다. 원 단위 아래는 버린다.
6. 1인당 비용을 규정 1의 상한(215,000원)과 비교한다.
7. 실외 프로그램이 있으면, 그 프로그램을 우천 대안으로 바꿨을 때의 합계와 1인당 비용을 따로 낸다.

## 출력 형식

| 항목 | 후보 | 견적 금액 | 부가세 | 부가세 포함 금액 | 수량 | 금액 |
|---|---|---|---|---|---|---|
| 숙박 | V0 | 0 | 포함/별도 | 0 | 인원 | 0 |
| 세미나실 | V0 | 0 | 포함/별도 | 0 | 1 | 0 |
| 1일차 저녁 | M0 | 0 | 포함/별도 | 0 | 인원 | 0 |
| 2일차 점심 | M0 | 0 | 포함/별도 | 0 | 인원 | 0 |
| 교통 | T0 | 0 | 포함/별도 | 0 | 대수 | 0 |
| 프로그램 | A0 | 0 | 없음 | 0 | 인원 | 0 |

- 합계: 0원
- 1인당: 0원 (상한 215,000원 이내 / 초과)
- 우천 대안으로 바꿨을 때: 합계 0원, 1인당 0원 (이내 / 초과)

## 하지 않는 것

- 견적 파일에 없는 금액을 지어내지 않는다.
- 후보를 바꾸지 않는다. 주어진 선택의 금액만 계산한다.
- 주류가 든 프로그램이 있으면 계산은 하되, 규정 4에 걸린다고 한 줄로 알린다.
