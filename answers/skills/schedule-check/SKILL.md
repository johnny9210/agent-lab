# 일정표 확인

일정표는 앞 칸이 뒤 칸을 정한다. 한 줄씩 따로 보지 않고 처음부터 끝까지 이어서 확인한다.

## 순서

1. 요일을 정한다. 1일차는 2026년 12월 10일 목요일, 2일차는 12월 11일 금요일이다.
2. 일정표의 줄을 시간 순서로 놓고, 앞 줄의 끝 시각이 다음 줄의 시작 시각보다 늦지 않은지 본다.
3. 아래 항목을 하나씩 확인한다. 근거가 되는 값은 요청서와 견적 파일에서 직접 옮긴다.

| 확인할 것 | 볼 자료 | 규정·요청 |
|---|---|---|
| 1일차 출발이 13:00 이후인가 | `data/request.md` | 요청 |
| 2일차 본사 도착이 17:00 이전인가 | `data/request.md` | 요청 |
| 이동 시간이 숙소의 편도이동분 이상인가 | `data/venues.csv` | 5 |
| 1일차에 세미나 2시간이 있는가 | `data/request.md` | 요청 |
| 식사가 60분 이상인가 | 일정표 | 15 |
| 식당이 그 요일에 문을 여는가 | `data/meals.csv`의 휴무요일 | 7 |
| 프로그램 시간이 소요분 이상인가 | `data/programs.csv` | 요청 |
| 실외 프로그램이 운영시간 안인가 | `data/programs.csv` | 13 |
| 세미나 말고 프로그램이 2개 이상, 합쳐 3시간 이상인가 | `data/request.md` | 요청 |
| 공식 일정이 22:00 전에 끝나는가 | 일정표 | 12 |
| 겹치는 시간이 없는가 | 일정표 | 15 |

## 출력 형식

| 확인할 것 | 결과 | 근거 값 |
|---|---|---|
| (위 표의 항목을 한 줄씩) | 맞음 / 틀림 | (파일의 값과 일정표의 시각) |

- 틀린 줄: (일차, 시간, 무엇이 문제인지)

## 하지 않는 것

- 후보를 바꾸지 않는다. 주어진 선택으로 일정표가 맞는지만 본다.
- 운영시간이나 휴무요일을 짐작하지 않는다. 견적 파일의 값을 쓴다.
