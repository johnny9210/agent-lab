# 싱글 에이전트에서 멀티 에이전트로 (Codex 실습)

Codex에서 에이전트 하나로 일을 시켜 보고, 담당 에이전트(TOML)를 직접 만들어 여럿이 나눠 하게 바꾸는 실습 폴더입니다.
소재는 가상 회사의 1박 2일 워크숍 기획입니다. 회사와 사람은 모두 가상입니다.

## 받는 방법

1. 이 화면 위쪽의 초록색 **Code** 버튼을 누르고 **Download ZIP**을 고릅니다. 로그인은 필요 없습니다.
2. 내려받은 `agent-lab-main.zip`의 압축을 풉니다.
3. ChatGPT 앱의 Codex 화면에서 **폴더 열기**로 `agent-lab-main` 폴더를 엽니다. 폴더를 신뢰할지 물으면 신뢰를 고릅니다.

따라 하는 순서는 [guide.pdf](guide.pdf)에 있습니다. 내려받은 폴더 안에도 같은 파일이 들어 있습니다.

## 실습

| 실습 | 전략 | 무엇을 하나 |
|---|---|---|
| 1 | 싱글 에이전트 | 에이전트 하나가 처음부터 끝까지 한다 |
| 2 | 멀티 에이전트 팀 | 담당을 만들어 같은 일을 나눠서 다시 한다. 작성–검토 반복, 병렬 조사, 지휘자–작업자 |
| 3 | 비교와 반례 | 싱글과 멀티를 비교하고, 멀티가 안 맞는 일을 본다 |
| 4 | 분류해서 넘기기 | 들어온 메일을 먼저 분류하고, 분류에 맞는 담당에게만 넘긴다 |

## 폴더

| 위치 | 내용 |
|---|---|
| `AGENTS.md` | 메인 에이전트의 지침과 기획안 형식 |
| `data/` | 요청서, 사내 행사 규정 16개, 참가자 명단, 견적 |
| `mail/` | 실습 4에서 쓰는 받은 메일 12통과 메일 처리 기준 |
| `.codex/agents/` | 담당 에이전트 TOML을 넣는 곳. 처음에는 비어 있습니다 |
| `.codex/config.toml` | 동시에 띄울 수 있는 담당 수 |
| `.agents/skills/` | 스킬을 넣는 곳. 처음에는 비어 있습니다 |
| `originals/`, `templates/` | 가져와서 고칠 원본 TOML 2개, 담당 에이전트 빈 틀 |
| `plan/`, `research/`, `review/` | 결과 파일이 저장되는 곳 |
| `answers/` | 막혔을 때 보는 예시 답안 |

`originals/`의 TOML은 VoltAgent/awesome-codex-subagents(MIT)에서 가져왔습니다.
