# 싱글 에이전트에서 멀티 에이전트로 (Codex 실습)

Codex에서 에이전트 하나로 일을 시켜 보고, 같은 일을 서브에이전트(TOML) 여럿이 나눠 하게 바꾸는 실습 폴더입니다. 서브에이전트와 스킬은 폴더에 들어 있습니다.
소재는 가상 프라이빗뱅크의 펀드 질의 응답 도우미입니다. JP모건 프라이빗뱅크의 리서치 도우미 "Ask David"의 구조를 본떴습니다. 회사, 펀드, 사람, 숫자는 모두 가상입니다.

## 받는 방법

1. 이 화면 위쪽의 초록색 **Code** 버튼을 누르고 **Download ZIP**을 고릅니다. 로그인은 필요 없습니다.
2. 내려받은 `agent-lab-main.zip`의 압축을 풉니다.
3. ChatGPT 앱의 Codex 화면에서 **폴더 열기**로 `agent-lab-main` 폴더를 엽니다. `AGENTS.md`가 바로 보이는 폴더를 엽니다. 폴더를 신뢰할지 물으면 신뢰를 고릅니다.

따라 하는 순서는 수업에서 받은 실습 슬라이드에 있습니다.

## 실습

| 실습 | 전략 | 무엇을 하나 |
|---|---|---|
| 1 | 싱글 에이전트 | 그냥 맡겨 보고, 스킬이 붙은 작성 서브에이전트에게 다시 맡긴다 |
| 2 | 멀티 에이전트 팀 | 같은 일을 서브에이전트가 나눠서 다시 한다. 검토하고 고치기, 병렬 조사, 나눠 맡기고 모으기. 끝에 싱글과 멀티를 비교한다 |
| 3 | 분류해서 넘기기 | 새로 들어온 질문을 먼저 분류하고, 답해도 되는 질문만 서브에이전트에게 넘긴다 |

## 폴더

| 위치 | 내용 |
|---|---|
| `AGENTS.md` | 이 폴더에서 일하는 모든 에이전트가 읽는 지침. 팀 구성, 답변 절차, 질문 절차, 답변 메모 형식 |
| `extra_rules.md` | 팀이 더한 기준. 처음에는 비어 있고 실습 2-A에서 한 줄을 더합니다 |
| `data/` | PB 질문 10건, 답변 작성 기준 14개, 펀드 24개의 기본 정보와 월 수익률, 문서 73개 |
| `inbox/` | 실습 3에서 쓰는 새 질문 12건과 질문 처리 기준 |
| `answers/answers.md` | 질문 10건과 새 질문 12건의 정답. 사람이 직접 열어 결과와 견줘 봅니다. 에이전트는 열지 않도록 `AGENTS.md`에 적어 두었습니다 |
| `.codex/agents/` | 서브에이전트 TOML 6개 |
| `.codex/config.toml` | 동시에 호출할 수 있는 서브에이전트 수 |
| `.agents/skills/` | 스킬 3개 |
| `memo/`, `research/`, `review/` | 결과 파일이 저장되는 곳 |

서브에이전트 지침의 다섯 칸 틀(일하는 순서, 집중할 것, 확인할 것, 출력 형식, 하지 않는 것)은 VoltAgent/awesome-codex-subagents(MIT)의 틀을 따랐습니다.
