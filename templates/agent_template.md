# 서브에이전트 빈 틀 (Claude Code)
# 이 파일을 .claude/agents/ 로 복사하고, 파일 이름과 아래 내용을 바꿔 쓴다.
# 꼭 있어야 하는 항목은 name 과 description 이다. '#'으로 시작하는 줄은 설명이므로 지워도 된다.

# 이름. 영어 소문자와 붙임표(-)만 쓴다. 대화에서 이 이름으로 부른다.
name: agent-name

# 한 문장 소개. 메인 에이전트가 이 문장을 보고 누구에게 맡길지 고른다.
# "무엇을 읽고, 무엇을 판단해서, 어디에 저장하는 서브에이전트"인지 적는다.
description: ...

# 이 서브에이전트가 시작할 때 미리 읽을 스킬. 쓰지 않으면 이 세 줄을 지운다.
skills:
  - skill-name
